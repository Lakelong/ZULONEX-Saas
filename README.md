# ZULONEX 总部管理后台体验原型

这是基于现有总部管理后台业务模型制作的 Vue3 + Vite 体验层验证工程。项目只优化信息层级、检索、筛选、状态反馈和任务处理效率，不改变线上业务对象、字段、流程、角色权限或数据范围。

当前使用脱敏模拟数据。页面能运行不代表对应业务已经完成接入；研发接入以 `src/online-system-baseline.js` 中的线上核验结果为准。

## 运行

```bash
npm install
npm run dev
```

打开 `http://localhost:5173/`。

## 生产构建

```bash
npm test
```

该命令会先执行业务契约校验，再生成 `dist/`。只运行构建可使用 `npm run build`。

`npm run build` 生成的是带“体验环境”标识的脱敏预览包。正式环境发布必须执行：

```bash
npm run build:production
```

该命令会在构建前强制检查登录身份、真实角色、数据范围、列表/详情接口、20 个写接口以及模拟数据替换状态。当前真实接口尚未接入，因此正式构建会被正确阻断，禁止绕过。完整说明见 `docs/DEPLOYMENT-READINESS.md`。

## 原型范围

- 超级管理员、总部运营、交付负责人、导学师、学管师、规划师、质控专员、客服、商家负责人、财务人员、合作审核员十一种工作视角演示，不作为正式角色权限依据
- 十一类角色的岗位待办、菜单收敛、动作阻断、默认数据范围和敏感字段展示策略联动
- 订单与售后、交付履约、合作伙伴、财务结算任务队列
- 全局搜索、筛选、批量选择、分页、详情抽屉和操作反馈
- 工作台待办直达具体业务对象，并同步完成状态
- 支付流水核验、交付中心分单、付款提醒和退款审核
- 推荐教师分配、连续排课、冲突时段处理和授课方式确认
- 采购付款凭证、物流登记、到货确认和采购退供处理
- 商家资料逐项核验、风险分级、初审复审和退回原因校验
- 结算账单的业务金额、应收、应付、已结、差额、发票和打款状态核对
- 业务处理操作记录与状态变更留痕
- 对齐现有后台的 13 个一级模块和 62 个子模块
- 基础、合作、学习、订单、采购、财务、招商、营销、成长、微信和系统台账
- 子模块级字段模型、状态筛选、字段显隐、横向完整表格和详情抽屉
- 全局搜索可跨订单、学员、商家和业务台账直达详情
- 经营指标、趋势图、交付中心排行和权限接入基线
- 360 至 1440 像素宽度的响应布局与移动端角色切换

## 业务核验状态

- 已核验主导航：13 个模块、62 个页面路由
- 原型字段契约已覆盖：13 个模块、62 个页面路由
- 已纳入严格字段一致性校验：基础管理、合作中心、学习中心、线上订单、线下订单、线上采购、线下采购、财务报表、招商管理、营销中心、成长中心、微信服务号、系统管理
- 已建立权限预览契约：11 类角色、23 项动作权限、7 组数据范围和 11 类敏感字段
- 已接入体验层联动：角色切换会同步更新菜单、范围、列表数据、分页总数、字段脱敏和提交动作
- 已建立正式接口门禁：9 项运行身份字段、5 条核心流程、20 个状态写操作及 8 条接入保护规则
- 待真实接口接入前复核：角色按钮权限、数据范围、字段脱敏、线上接口字段名和后端状态枚举
- 待完成线上权限级核验：绑定真实角色 ID，并逐项替换当前体验策略
- 待真实接口绑定：列表、详情与 20 个写接口地址当前保持空值，禁止猜测接口后模拟成功

订单对象已严格区分学员、家长、家长手机号、经销商、销售方、代下单经销商、来源、平台、下单方式和渠道，禁止重新合并为“客户”或单一“来源”。

当前严格校验还会检查订单、交付、采购之间的关联一致性。例如同一订单号下的学员、家长、手机号和课程必须一致；若研发接接口后字段缺失或对象关系冲突，`npm test` 会直接失败。

## 研发接入

- 页面与交互：`src/App.vue`
- 视觉样式：`src/style.css`
- 模拟数据与字段结构：`src/prototype-data.js`
- 核心业务对象、状态转换和数据范围规则：`src/business-contract.js`
- 登录身份、接口载荷、审计回执与接入门禁：`src/integration-contract.js`
- 业务模块、子模块和台账字段：`src/module-registry.js`
- 线上路由、字段、筛选和动作契约：`src/online-system-baseline.js`
- 角色权限默认拒绝与核验入口：`src/permission-baseline.js`
- 业务契约自动校验：`scripts/verify-business-contract.mjs`
- 核验说明与接入门禁：`docs/ONLINE-SYSTEM-BASELINE.md`
- 旧版数据看板：`src/LegacyDashboard.vue`、`src/legacy-dashboard.css`

正式接入必须逐页面完成字段、筛选、状态、动作和数据范围五项对照。接口适配层应将现有接口字段映射到页面业务对象，不允许通过隐藏、改名或合并字段来迁就当前演示数据。
