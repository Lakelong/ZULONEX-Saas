# 正式环境部署门禁

## 当前结论

- 体验/灰度环境：可以部署，用于角色、流程、字段和交互验收。
- 正式业务环境：暂不可部署。前端已设置强制门禁，缺少真实接入时构建必须失败。

## 已通过

- Vue 生产构建与业务契约校验
- 13 个模块、62 个线上路由字段契约
- 11 类角色的菜单、动作、数据范围和字段脱敏预览
- 订单、交付、采购、入驻、结算五类核心流程演示
- 桌面和 390px 手机端布局、角色切换与横向溢出检查
- 依赖安全审计，无已知高危漏洞
- 体验/正式环境标识、生产模式模拟写入锁定、启动失败兜底

## 正式上线阻断项

1. 登录态 9 项运行字段尚未绑定。
2. 11 类角色尚未绑定真实线上角色 ID 和权限码。
3. 数据范围仍为体验规则，未由后端返回范围类型与对象 ID。
4. 5 个列表接口、5 个详情接口、20 个写接口尚未绑定。
5. 页面仍加载脱敏模拟数据，尚未接入真实查询与分页。
6. 写操作仍是体验层本地状态变更，尚未接入幂等、乐观锁和审计回执。
7. 导出、导入、消息通知、文件上传等外围能力尚未接真实服务。

## 研发接入顺序

1. 接登录会话与当前用户上下文。
2. 接真实角色、按钮权限和数据范围。
3. 先接五类列表/详情接口并完成字段映射。
4. 按订单、交付、采购、入驻、结算顺序接 20 个写接口。
5. 接口回执必须包含 `requestId`、`auditId`、`status`、`updatedAt`、`version`。
6. 移除页面模拟数据依赖，补接口错误、空状态、冲突和重试体验。
7. 执行 `npm test`、`npm run check:production`、`npm run build:production`。

## 发布要求

- Node.js 20 或更高版本。
- 正式环境设置 `VITE_APP_MODE=production`。
- Web 服务器配置 HTTPS、SPA 回退和安全响应头。
- 禁止跳过 `check:production` 直接上传普通 `dist/` 作为正式业务系统。
